# DR Arquitetura e Engenharia

Landing page estática com HTML, CSS, GSAP, ScrollTrigger e Lucide Icons.

## Executar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Antes de publicar
- Substitua `contato@drarquitetura.com.br` pelo e-mail oficial.
- Revise nomes e categorias dos projetos.
- Para produção, mantenha conexão com a internet para carregar fontes, GSAP e ícones via CDN.
